# Compras / BOM — MDMX-OUT4

## Estado

Pendiente de cerrar tres carritos equivalentes y con enlaces actuales/verificados:

1. AliExpress.
2. Amazon.
3. Chile/Santiago: compra presencial o Mercado Libre.

## Alcance común

Cada carrito debe permitir construir y validar el mismo bench, no tres arquitecturas distintas.

Debe cubrir como mínimo:

- RP2040 / placa de desarrollo adecuada;
- cuatro canales de interfaz RS-485/DMX;
- aislamiento por salida;
- conectores XLR-5 o elementos necesarios para cableado de bench;
- alimentación/regulación;
- protección necesaria de línea;
- prototipado/cableado;
- terminación de prueba;
- elementos de medición/adaptación indispensables para validar la cadena.

## Criterio de selección

No comprar módulos “RS-485” a ciegas. Cada pieza debe verificarse respecto del uso real:

- 250 kbaud DMX;
- dirección TX;
- niveles lógicos compatibles;
- aislamiento real cuando se anuncie;
- alimentación;
- disponibilidad;
- conectividad física;
- posibilidad de replicar cuatro salidas.

Los enlaces y precios no se congelan en este documento hasta ser verificados en la etapa de compra.
